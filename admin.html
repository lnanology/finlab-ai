Stripe Account
Live check against Stripe's own Account.retrieve() -- not just whether STRIPE_SECRET_KEY/price IDs are set (see the public /stripe/status for that). This answers whether the account can actually accept charges and pay out right now, and exactly what Stripe is still waiting on if not.

API Trending Tickers
Aggregate-only signal: which tickers/endpoints Intelligence API consumers actually query, across all keys/tiers. Endpoint+ticker+timestamp only -- never the response payload, and never which specific key queried what. This is what "letting people use a free key" actually gets you back: a product signal (what developers care about), not engine training data or graded accuracy (that's the separate Prediction Ledger, which only grades this site's OWN internal predictions).

Data Factory
Foundation layer for auto-extensible external data collectors (FRED, SEC EDGAR, CFTC COT, crypto exchanges, etc.). Each collector self-registers the moment its module is imported -- no code change needed here to see a new one appear. Toggle a source off if it's failing or you want to pause it; failures also email you directly (deduped to once per 6h per source).
Registered Sources
CFTC Commitments of Traders -- Net Positioning
Net long/short = Non-Commercial (fund) longs minus shorts. Positive = funds net long. Weekly data, published Fridays.
SEC 13F Institutional Holdings
Latest quarterly 13F holdings for watched concentrated managers. Select a filer to see their top positions by value.
Select a filer above
Binance Exchange Market Data
Real single-exchange 24h price change/volume for 10 major coins (Binance spot) -- distinct from the CoinGecko cross-exchange average used elsewhere on the site.
EIA Energy Prices & Storage
WTI crude + Henry Hub natural gas spot prices, plus Lower-48 gas storage -- pairs with the CFTC oil/gas COT contracts above (positioning vs. physical fundamentals). Requires EIA_API_KEY.
US Treasury Fiscal Data
Total public debt outstanding + Treasury General Account cash balance -- the fiscal side of liquidity, distinct from FRED's Fed-side series above. No API key required.
Coinbase Exchange Market Data
Same 10 coins as the Binance panel, sourced from Coinbase instead -- lets a second real exchange's price/volume be compared against Binance's.
SEC Form 4 Insider Trading
Per-ticker lookup (not a fixed list, unlike CFTC/EIA above) -- most recent Form 4 filings' non-derivative (open-market) transactions for a company's own directors/officers/10% owners.
Enter a ticker above
FINRA Equity Short Interest
Per-ticker lookup, biweekly settlement data from FINRA's public flat files. Days-to-cover = short interest ÷ average daily volume.
Enter a ticker above
SEC XBRL Company Facts (Fundamentals)
Per-ticker lookup -- latest annual (10-K) revenue, net income, diluted EPS, total assets/liabilities and operating cash flow, straight from SEC XBRL. No API key required.
Enter a ticker above
CBOE VIX Term Structure
VIX9D / VIX / VIX3M / VIX6M -- contango (calm) vs. backwardation (stress) shape of the options market's own forward volatility view. No API key required.
FDIC Bank Health
Lead bank subsidiary Call Report data (ROA/ROE/assets/equity) for JPM, BAC, WFC, C, USB, PNC, TFC. Reflects the regulated bank subsidiary, not consolidated holding-company financials. No API key required.
USDA Agricultural Prices
Corn/wheat/soybean price received by farmers -- pairs with CORN/WEAT/SOYB ETFs the same way EIA pairs with USO/UNG (positioning vs. physical fundamentals). Requires USDA_NASS_API_KEY.
Prediction Ledger
